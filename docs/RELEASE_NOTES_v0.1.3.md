# v0.1.3 发布说明

## 新增

- **Grid 显式定位（`place`）与跨格（`span`）**
  半开区间 `place("a", 0..3, 0..1)`；`span("b", 2, 1)` 只声明尺寸、位置交给自动流。
  两者互斥：`place` 定"在哪"，`span` 定"多大"，都不调 = 自动流 1×1（同 CSS `grid-column: span 2`）。
- **最长路轨道归因（精确解，替代两遍法近似）**
  设前缀和 `P`，区间约束变成 `P[b] - P[a] >= d`；因 `a < b`，约束图是 DAG，
  下标序即拓扑序，一遍松弛得**最小总宽的精确解**，`O(m+n)`。
- **`y901-core::interval`**（区间集合：`insert` / `first_gap` / `overlaps` / `covered_len`）
  可复用于 TreeView 虚拟化范围计算、脏区合并、多窗口语义合并。
- **`children_clip` 支持区间并集**
  跨格控件裁剪到"列并集 + 区间内间距"，而不是起始那一格。

## 性能

| 基准 | 预算 | 实测（release） |
|---|---|---|
| 10k 节点布局（含 50 跨格） | ≤ 3ms | **1.25ms** |
| 10k 次 `place` 批量配置 | ≤ 50ms | **1.83ms** |

两个基准都已进回归（非 `#[ignore]`），阈值按 debug/release 分开，防止 CI 慢机器假红。

## 已知限制

- 自动流只支持**行优先**（`grid-auto-flow: row`），不支持列优先与 `dense` 回填
- `span` 放不下时**退化为 1×1**（+ 一次性警告），不动态加行
- 跨格裁剪是**并集矩形**，不支持圆角裁剪
- `Fixed` 轨道可能被跨格约束撑开（否则跨格内容放不下）
- 行与列**分别求解**，不支持二维耦合约束（例如"格子必须是正方形"）
